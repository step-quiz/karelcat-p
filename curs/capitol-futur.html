D'en Karel al Python

Resum: tot el que saps

Instruccions: el que en Karel fa

move()          # avança una casella
turn_left()     # gira a l'esquerra
turn_right()    # gira a la dreta
turn_around()   # fa mitja volta
grab()          # agafa una perla
drop()          # deixa una perla

Condicions: el que en Karel pregunta

front_is_clear()     # al davant està lliure?
front_is_blocked()   # al davant hi ha una roca o la vora?
left_is_clear()      # a l'esquerra està lliure?
right_is_clear()     # a la dreta està lliure?
pearl_here()         # aquí hi ha una perla?
bag_is_empty()       # la motxilla és buida?
bag_has_pearls()     # a la motxilla hi ha perles?

Estructures: la forma del programa

for i in range(5):        # repeteix 5 vegades
    move()

while front_is_clear():   # repeteix mentre al davant està lliure
    move()

if pearl_here():          # si aquí hi ha una perla...
    grab()
else:                     # si no...
    move()

def ves_al_final():       # una instrucció nova
    while front_is_clear():
        move()

Combinar condicions: and, or, not

while front_is_clear() and not pearl_here():   # i · no
    move()

if front_is_blocked() or pearl_here():         # o
    turn_around()

Tot el que has escrit és Python

Tot el codi del curs és Python. Python de veritat!

for, while, if, def, and, or, not: tot això és Python.

Amb en Karel, les instruccions són move(), grab()…
Amb Python pots fer moltes més coses: jocs 🎮, càlculs 🔢 i pàgines web 🌐.

En Karel i Python s'assemblen molt

Mira: la forma és la mateixa. Només canvien les instruccions de dins.

# Karel                     # Python
for i in range(3):          for i in range(3):
    move()                      print("Hola!")

def puja_grao():            def saluda():
    turn_left()                 print("Hola!")
    move()                      print("Com estàs?")
    turn_right()
    move()

print() escriu un text a la pantalla.

Què té Python de nou?

Python pot recordar números i paraules. Es diuen variables.

punts = 0             # els punts comencen a 0
punts = punts + 10    # ara hi ha 10 punts
print(punts)          # escriu 10

Python també et pot fer preguntes:

nom = input("Com et dius? ")
print("Hola, " + nom + "!")

Les idees que sempre serviran

Si aprens un altre llenguatge de programació, hi trobaràs les mateixes idees:

  • 🔁 Repetir: for i while.
  • 🔀 Decidir: if i else.
  • 🧩 Crear instruccions noves: def.
  • ✂️ Dividir un problema en parts petites.
  • 🐞 Buscar els errors i corregir-los.
